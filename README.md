# REFLECTIONS

For this project I faced a lot of challenges, but for most of them I was able to figure out on my own until I got to storing the posts to the local storage. The biggest challenge I faced was adding my posts to local storage and getting the posts to stay on the page after a page refresh or after closing the browser. I changed my code up several times trying to get it right. I found that I had to store my posts as objects in an array for it to store more than one post. I also had some event listener stacking that I was unaware of, and it was causing a bug in my code that made my edit post button change all posts to the same thing. Overall, I learned a lot with each challenge and made sure to read the reasoning behind each mistake in my code.
