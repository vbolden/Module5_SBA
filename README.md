# REFLECTIONS

For this project I faced a lot of challenges, but for most of them I was able to figure out on my own until I got to storing the posts to the local storage. I used the form template given in class for the HTML and CSS of the website layout then changed up the styling a bit. The biggest challenge I faced was adding my posts to local storage and getting the posts to stay on the page after a page refresh or after closing the browser.
